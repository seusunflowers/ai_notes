# NSFC 重点国际（地区）合作研究项目 —— "单方评审"调研

> 调研日期：2026-10-22（对应 2026 年度项目指南周期；2027 年度指南征订通知已发布，新指南预计 2027 年初出）。
> 全部结论来自 nsfc.gov.cn 官方指南/通知原文、官方 PDF、指南附图 OCR。标「未核实」的条目需自行向基金委确认。

## 0. 结论

用户所问的"不要求合作国家、合作书仅由我方评审"的国自然项目，主渠道是
**重点国际（地区）合作研究项目**（简称重点国合）。它与**组织间国际（地区）合作研究项目**
并列，后者必须走双渠道。

- 重点国合：NSFC 自主设立，**"须由具有合作基础的中方科学家单独向基金委申请"**
  （2025 版指南海报原文），外方合作者不向其本国任何机构申报；外方只提供签字的协议、
  简历、确认页作为附件，我方单方评审。
- 组织间：外方须同时向本国资助机构提交申请，**"单方提交的项目申请将不予受理"**，
  由双方资助机构共同评审。

## 2. 单方评审 vs 组织间双渠道

| | 重点国际（地区）合作 | 组织间国际（地区）合作 |
|---|---|---|
| 设立方式 | NSFC 自主设立 | NSFC 与境外资助机构协议框架下 |
| 绑定国家 | **不绑定** | 绑定（中韩 NSFC-NRF、中伊 NSFC-INSF、中塞 NSFC-SFRS、中埃 NSFC-ASRT、中意 NSFC-MAECI 等） |
| 提交方式 | 中方单独向基金委申请 | 双方均须向各自资助机构提交，**单方提交不予受理** |
| 评审 | 基金委单方评审 | 联合资助方共同评审、共同决定 |
| 境外合作者资格 | 副教授以上 + 独立主持实验室 | 须符合外方资助机构资格要求 |
| 期限 | 一般 5 年 | 一般 3–5 年 |
| 典型强度 | 约 220–240 万/项 | 约 40–200 万/项（多为 3 年） |

2026 年度组织间示例（双渠道，勿误选）：中韩 ≤150 万/3 年（6/29–8/10）、
中伊 ≤60 万/3 年（7/18–8/22）、中塞 ≤150 万/3 年（8/24–9/25）、
中埃 ≤40 万/3 年（8/3–9/11）、中意 ≤200 万/3 年；多边：e-ASIA（英文提交 e-ASIA 秘书处）、
BRICS STI（brics-sti.org 在线联合申报）；港澳：NSFC-RGC 港澳重点项目 ≤300 万/4 年
（双方各自评审 + 联合评审）。

## 3. 同样具有"单方性质"的其他国际类项目（备选通道）

1. **国家科技平台开放合作专项（IOCBRF，2026 新设试点）** — 面向全球的科学研究基金项目下。
   重点合作项目（≤230 万/4 年，约 15 项）+ 合作探索项目（≤60 万/3 年，约 25 项）。
   中外双负责人申请制，申请书正文须英文，中外双方签署的合作协议作为附件提交，
   外方不向本国机构申报；附件含平台《准入同意函》、合作协议、英文简历、外方在职证明；
   外方须全职国外工作、副教授及以上、在华累计 ≥30 天/年；
   **不计入"申请和承担项目总数限 2 项"**。2026 申报期 8/7–9/11 16:00（已过）。
2. **锦屏重大科学设施国际合作研究计划专项**（2025 设立）— 须与外国联合团队共同申请
   并签署合作研究协议，另需 CJPL 公章同意函，申请书正文英文；集成项目约 1000 万/4 年，
   培育项目 80–120 万/4 年；计入"总数限 2 项"。2026 申报期 6/30–8/5（已过）。
3. **NSFC-CERN 重大科学设施国际合作研究计划专项** — 集成/重点支持/培育项目；
   探测器研制须附 CERN 四大探测器实验发言人签名的合作研究证明；仅中方评审。
4. **可持续发展国际合作科学计划（SDIC）第二批**（2026-06-05）— "战略性合作研究项目/
   合作交流项目，主要面向中方自主牵头实施"；能力培育 ≤60 万、重点 ≤200 万、
   青年科学家交流 ≤30 万、国际研讨会 ≤30 万，3 年期，外方副教授以上并独立主持实验室。
   （第一批多为组织间双渠道。）

## 4. 实操清单（重点国合）

1. 确定 5 名以内的境外合作者（副教授以上、独立主持实验室），取英文简历 + 本人签署的
   合作确认页（≤800 字）。
2. 与外方签署**合作研究协议**：合作内容与目标、双方负责人和主要参与者、期限/方式/计划、
   知识产权归属与使用转移、经费预算（《国家自然科学基金国际（地区）合作研究项目管理办法》
   第 13 条要求项，也是附件审查重点）。
3. 英文摘要 + 中方申请书；附件缺一不予受理。
4. 限项：国际（地区）合作类项目"作为申请人申请 + 作为负责人正在承担"合计限 1 项
   （当年资助期满的不计入统计）。组织间项目仅当直接费用超 200 万/项才计入
   "申请和承担项目总数限 2 项"；**重点国际项目是否计入总数 2 项：未核实**，
   以当年《申请规定》原文/新指南为准。
5. 接收方式：国际（地区）合作研究与交流项目为**非集中接收/随时受理**
   （2026 年度集中接收期仅 3/1–3/20）；2027 年度指南征订通知已于 2026-10 发布，
   新指南预计 2027 年初出，届时按新海报更新领域方向与强度。
